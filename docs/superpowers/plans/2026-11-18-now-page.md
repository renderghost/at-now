# now.renderg.host Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A standalone Now page at now.renderg.host that assembles itself from Barry's AT Protocol PDS, in renderg.host's design system, served by one cached `/api/now` endpoint.

**Architecture:** Pure, framework-free rule logic in `src/core` (time windows, per-theme selectors, hydration) is shared by a Vercel Node function (`api/now.ts`, Web-standard `GET`) and the React SPA (`src/app`). The function fetches the PDS and lookups through an injectable `AtSource`, so every rule is unit-tested against recorded fixtures with a fixed clock. The page makes one request and renders ordered, non-empty themes.

**Tech Stack:** Vite 8 + React 19 + TypeScript 6 (strict) + Tailwind CSS 3.4 + Vitest 5 (+ jsdom, Testing Library) on Vercel (Node runtime, `fra1`).

**Spec:** `docs/superpowers/specs/2026-11-18-now-page-design.md`

## Review Focus

1. **A remote server hangs or 500s** (an organiser's PDS, the AppView): only that theme or highlight disappears; the endpoint still answers within `maxDuration`. → Task 9 test `isolates a failing theme`.
2. **Odd date strings** in real records (`2026-11` month precision, microseconds `…59.418214Z`, offsets `+03:00`, garbage): parsed or skipped, never thrown. → Task 2 `parseDate` tests + Task 5 malformed-record test.
3. **The whole API fails or returns nothing**: the page still shows title, intro and a neutral sentence linking to renderg.host, never a blank screen or spinner forever. → Task 10 test `renders fallback when the API fails`.
4. **Status with no `expires` or an expired one**: no `expires` ⇒ normal 7/30-day rules on `createdAt`; expired ⇒ hidden. → Task 5 status tests.
5. **Missing optional media/fields** (book without cover, event without location, post without embed, gallery with one photo, track without artwork): cards render placeholders, no broken images or dangling separators. → Task 11/12 render tests with stripped items.

- Produces (`source.ts`): `AtRecord<T> = { uri: string; cid: string; value: T }`, `Profile = { did; handle; displayName?; avatar? }`, `PostView = { uri; author: Profile; text: string; createdAt: string }`, and

  ```ts
  interface AtSource {
    listAll<T>(collection: string): Promise<{ records: AtRecord<T>[]; capped: boolean }>;
    listSince<T>(collection: string, since: Date): Promise<{ records: AtRecord<T>[]; capped: boolean }>;
    getRecord<T>(uri: string): Promise<AtRecord<T> | null>;   // null on 404/RecordNotFound
    getProfiles(dids: string[]): Promise<Profile[]>;          // batches of 25
    getPosts(uris: string[]): Promise<PostView[]>;            // batches of 25
    resolvePds(did: string): Promise<string>;                 // cached; did:plc via PLC, did:web via /.well-known/did.json
  }
  createHttpSource(opts: { did: string; pdsUrl: string; appviewUrl: string; plcUrl: string; timeoutMs: number; maxConcurrency: number; maxPages: number; now: () => Date; fetchImpl?: typeof fetch }): AtSource
  ```

`listSincePages` algorithm (adaptive time slices; tested on eurosky: any TID is a valid cursor):

```
p1 = page(undefined); keep records with tid ≥ since
if p1 has < PAGE_SIZE records, or its oldest tid < since, or no cursor → done
oldest = tidToDate(last rkey of p1)
rate = PAGE_SIZE / (now − oldest)                    // records per ms
slices = clamp(ceil((oldest − since) × rate / PAGE_SIZE × 1.25), 1, maxPages − 1)
boundaries b0 = oldest, b1 … b_slices = since (evenly spaced)
for each slice i in parallel: cursor = dateToTid(b_i);
   loop page(cursor); keep tid ≥ b_{i+1}; stop when page short, oldest tid < b_{i+1}, or no cursor;
   share one page budget across slices (maxPages total); capped = budget exhausted before all slices finished
merge p1 + slices, dedupe by uri, sort by rkey desc
```
